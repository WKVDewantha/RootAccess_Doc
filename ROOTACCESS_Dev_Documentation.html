An in-depth technical dive into the ROOTACCESS application. This document details the technology stack, Inter-Process Communication (IPC) architecture, PowerShell service background execution, and the mathematical logic for state parsing.

# Technology Stack & Languages

⯈ Frontend (Renderer)

  • React 18: For modular component-based UI rendering.
  • TypeScript: Providing strict typings for all component props and state variables.
  • Tailwind CSS: For rapid utility-first styling without external CSS files.
  • Framer Motion: For fluid page transitions and component animations.
  • Recharts / Lucide: For dashboard data visualization and iconography.

⯈ Backend (Main Process)

  • Electron: Chromium-based wrapper allowing native desktop capabilities.
  • Node.js: Powers the backend event loop and `child_process` modules.
  • PowerShell 5.1/7+: The fundamental engine executing WMI queries, Winget parameters, and AD commands.
  • Vite: Ultra-fast bundler for compiling React and Electron payloads.

# Architecture & Directory Structure

ROOTACCESS rigidly separates concerns to prevent arbitrary code execution vulnerabilities in the renderer process.

ROOTACCESS/
├── electron/              # MAIN PROCESS
│   ├── main.ts            // Window lifecycle, IPC channel handlers
│   ├── api.ts             // ContextBridge preload script (Security Boundary)
│   └── powershell.ts      // The execution engine for OS commands
├── src/                   # RENDERER PROCESS
│   ├── components/        // UI Modules (Dashboard, Maintenance, etc.)
│   ├── context/           // React Providers (Auth, Theme)
│   ├── App.tsx            // Main component router view
│   └── index.css          // Tailwind imports and custom overrides
├── config.json            // Editable default settings (Domain, OUs, Packages)
└── package.json           // Dependency management and Vite build scripts

# Inter-Process Communication (IPC)

The React UI cannot interact with the Windows OS directly for security reasons. It communicates with Node.js via strict preloaded channels.

1. The Security Boundary (`api.ts`)

We use `contextBridge.exposeInMainWorld` to only permit specific commands to flow from React to Electron.


// electron/api.ts
contextBridge.exposeInMainWorld('systemAPI', {
    // Only allows sending specific events
    installSoftware: (id: string) => ipcRenderer.invoke('install-software', id),
    // Listens for stdout updates
    onInstallProgress: (callback: Function) => 
        ipcRenderer.on('install-progress', (_, data) => callback(data))
});

2. The Execution Engine (`powershell.ts`)

When Electron receives the `install-software` event, it invokes a detached `child_process.spawn` to run PowerShell seamlessly.


// electron/powershell.ts
export class PowerShellService {
    static installSoftware(packageId: string, win: BrowserWindow) {
        const ps = spawn('powershell.exe', [
            '-NoProfile', '-NonInteractive', 
            '-Command', `winget install ${packageId} --accept-source-agreements`
        ]);

        ps.stdout.on('data', (data) => {
            // Send live data back to React
            win.webContents.send('install-progress', data.toString());
        });
    }
}

# Mathematical Logic & Background Parsing

Parsing System Analytics (The Dashboard)

Windows Management Instrumentation (WMI) returns hardware memory metrics in raw bytes. The system polls this via `Get-CimInstance` every 3 seconds. The backend engine mathematically converts these raw bytes into human-readable Gigabytes.

Input: $Memory.FreePhysicalMemory (Returns Kilobytes)
Algorithm: GB = (KB / 1,048,576) [Rounded to 2 decimal places]
Percentage Calculation: (Used_RAM / Total_RAM) * 100

React takes this JSON formatted percentage to dynamically fill the radial progress bars in `Dashboard.tsx`.

Analyzing Winget JSON / Regex Progress

Winget natively outputs standard text streams to the terminal. To display a web GUI progress bar instead of a raw terminal block, the `SoftwareDeployment.tsx` component applies Regex matching against the `stdout` pipe from Node.

// STDOUT RAW STRING EXAMPLES:
Downloading... [========== ] 70%
// REGEX EXTRACTION:
const match = stdout.match(/\[.*\]\s+(\d+)%/);
if (match) setProgress(parseInt(match[1]));

Subnet Mask / CIDR Calculations

When assigning a Static IP in `NetworkConfig.tsx`, Windows requires an Integer mask (CIDR length, e.g., 24) rather than a string mask (e.g., 255.255.255.0).

The application calculates the Prefix Length dynamically by splitting the standard Subnet Mask, calculating the binary mapping, and reducing it into a solid integer count, routing it securely through `New-NetIPAddress -PrefixLength 24`.

HTML Report Generation Engine

The `AdvancedInfo.tsx` component features a proprietary generation engine that transforms the multi-layered JSON system state into a standalone, styled HTML document.

// TEMPLATE INJECTION:
const report = `<html><style>${css}</style><body>${generateTables(data)}</body></html>`;
// FILE SYSTEM IO via IPC:
await window.ipcRenderer.invoke('system:write-file', path, report);

This allows technicians to export a full machine audit without needing the application installed on the target viewing device.

Deployment Hub Processes (System Prep & Domain Join)

The deployment suite automates Windows workstation provisioning using PowerShell `child_process` wrappers.

  • System Prep: Executes scripts to rename the PC (`Rename-Computer`), activate Windows licenses via SLMGR, configure system timezones, and provision secondary disks using `Initialize-Disk` and `New-Partition`.
  • Domain Join: Securely passes credentials by converting plain-text strings into `System.Management.Automation.PSCredential` objects, safely invoking the `Add-Computer` cmdlet.

Policies Configuration

System policies are manipulated directly through the Windows Registry via `Set-ItemProperty` and `Get-ItemProperty` to instantly enforce or query rules.

  • Registry Manipulation: Modifies `HKLM` and `HKCU` keys to toggle features like USB Storage (`Start=4`), Command Prompt restrictions (`DisableCMD=1`), and RDP access (`fDenyTSConnections=0`).
  • Power Management: Leverages the `powercfg` utility to parse active scheme GUIDs and map them to standard UI power profiles.

System Maintenance

Maintenance operations wrap native Windows utilities to optimize the OS environment seamlessly from the UI.

  • Disk & Temp Cleanup: Invokes `cleanmgr` and clears user `Temp` directories recursively.
  • Event Logs: Executes `Clear-EventLog` across System and Application channels.
  • Network Reset: Resets networking stacks programmatically via `netsh winsock reset` and `ipconfig /flushdns`.

Advanced Network Suite

Network diagnostics are performed by wrapping low-level networking commands and parsing their structured output.

  • Connectivity Tests: Wraps `Test-Connection` (Ping) and `Test-NetConnection` / `tracert` (Traceroute) with Regex extraction for hop latency.
  • Port Scanning: Utilizes .NET `System.Net.Sockets.TcpClient` directly within PowerShell to rapidly check open ports without external dependencies.
  • Bandwidth Analytics: Polls network interface statistics to calculate accurate real-time TX/RX speeds.

# How to Extend the Codebase

Adding a new feature (like a new PowerShell script toggle) requires updating three layers of the app.

  1. Create the Service Layer (powershell.ts)
    Add a new static method inside `PowerShellService`. Use `exec()` for short outputs (like grabbing machine data) and `spawn()` for long-running processes (like installations).
  2. Map the IPC Route (main.ts & api.ts)
    Register the `ipcMain.handle` block inside `main.ts` pointing to your service. Next, expose a simple async function via `contextBridge` inside `api.ts`.
  3. Call it in React (UI Components)
    Inside your `.tsx` component, trigger the function `await window.systemAPI.yourFunction()`. Wrap it in a `try/catch` and update your component state accordingly.
